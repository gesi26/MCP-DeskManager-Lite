# MCP DeskManager

**Remote MCP server for Windows** by [Protime](https://protime.it/en/): let **Claude** and **ChatGPT** use your PC from any chat,
on the web, in the desktop apps or **from your phone**. No open ports and no fixed IP: a secure tunnel with OAuth is built in.

- Persistent terminals: PowerShell, CMD and WSL bash
- Files: read, write, search and edit, with automatic versions before every change
- Your real Chrome with your logins, plus a dedicated browser
- Desktop apps through UI Automation (native, Electron, Java)
- Email, screenshots, CPU/RAM/GPU monitoring and Telegram alerts
- One revocable key per assistant, confirmation before irreversible actions, activity log
