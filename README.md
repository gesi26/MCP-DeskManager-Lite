# DeskManager Lite is now **MCP DeskManager**

DeskManager Lite was the first version of our remote MCP server for Windows. It has been replaced by
**[MCP DeskManager](https://protime.it/en/deskmanager/)** by [Protime](https://protime.it/en/), which keeps everything Lite did and adds much more.

**MCP DeskManager** turns your Windows PC into a remote MCP server that **Claude** and **ChatGPT** can use from any chat:
web, desktop app or **your phone**. No open ports and no fixed IP: a secure tunnel with OAuth is built in.

- Persistent terminals: PowerShell, CMD and WSL bash
- Files: read, write, search, with versions
- Your real Chrome with your logins, plus a dedicated browser
- Desktop apps through UI Automation
- Email, screenshots, monitoring and Telegram alerts
- One key per assistant, revocable; confirmation for irreversible actions
